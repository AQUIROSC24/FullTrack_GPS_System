# FullTrack_GPS_System
Connection for Fulltrack API Rest Tracking System

Este proyecto en Python permite conectarse a la API de Fulltrack para consultar:

- ✅ Listado de clientes activos
- 🚨 Alertas del sistema
- 🚗 Vehículos por cliente
- 📍 Última ubicación de los vehículos de un cliente

---
El proveedor del servicio debe de brindar las credenciales necesarias, APIKEY y SECRETKEY.

## 📦 Requisitos

Python 3.8 o superior
Instalar dependencias:
```bash
pip install -r requirements.txt
